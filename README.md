# Steam Family Library

Статический сайт для GitHub Pages: быстрый поиск по названию, AppID и владельцам, фильтры, сортировка, избранное, карточки игр, импорт/экспорт JSON и резервные варианты загрузки обложек.

## Файлы
- `index.html` — весь интерфейс и логика сайта.
- `db.json` — демонстрационная база из 10 игр. Замените её своей базой либо импортируйте JSON через кнопку на сайте.

## Формат JSON
Поддерживаются массив объектов или объект с полем `games`/`items`. Рекомендуемый формат:

```json
[
  {
    "appid": "620",
    "name": "Portal 2",
    "owners": ["Family Library"],
    "copies": 1,
    "capa_url": "https://example.com/cover.jpg",
    "acquired": "2025-05-17"
  }
]
```

Также распознаются альтернативные имена полей: `appId`, `app_id`, `id`, `title`, `game`, `owner`, `users`, `libraries`, `cover_url`, `cover`, `image`, `header_url`, `copy_count`, `count`, `purchase_date`, `date`.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html`, `db.json` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
5. После публикации откройте показанный GitHub Pages URL.

## Обложки
Сайт использует `capa_url`, если он задан, затем пробует несколько стандартных URL Steam CDN на основе AppID. У Steam не у каждой игры есть изображение каждого типа; поэтому абсолютная гарантия обложки невозможна. Для некоторых игр `library_600x900.jpg` может отсутствовать, и тогда код пробует `header.jpg`.

## Приватность и безопасность
Сайт не просит пароль Steam, Steam Guard, API-ключ или токен. Избранное хранится локально в `localStorage` браузера. Каталог читается из `db.json` и импортируется пользователем локально. Изображения запрашиваются у внешних CDN Steam; для внешних CDN нужны сеть и доступность домена.
